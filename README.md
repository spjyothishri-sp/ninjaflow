# NinjaFlow — Liquidity Control Tower (Frontend)

This is a frontend-only Vite + React prototype for the NinjaFlow hackathon demo.

Quick start:

1. Install dependencies:

```bash
npm install
```

2. Start dev server:

```bash
npm run dev
```

Notes:
- This project uses Tailwind CSS. Run `npm install` to install dev dependencies.
- All data is mock/simulated in `src/mockData.js` and `src/api.js`.
- Demo flow: Dashboard → click entity → Get Financing → Simulate bank offer → Open Simulator
